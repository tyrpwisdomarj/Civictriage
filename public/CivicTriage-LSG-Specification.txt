MASTER APPLICATION BUILD SPECIFICATION PROMPT: CivicTriage LSG
==============================================================

Build CivicTriage LSG ("Kerala Smart Mobility & Civic"), a unified civic-tech, municipal triage, police safety, and interactive 3D Kerala & South India regional mobility platform designed for Kerala Local Self-Governments (LSGs / K-SMART workflows), Kerala Police (THUNA & Pol-App workflows), and regional travelers.

All 5 primary workspaces, interactive 3D scenes, modals, external alert hooks, local persistence, and the global context-aware AI assistant must interoperate through shared live session state.


----------------------------------------------------------------------
1. VISUAL DESIGN SYSTEM (THEME, COLORS & TYPOGRAPHY)
----------------------------------------------------------------------

1.1 Aesthetic & Surface Language
- Theme Mode: Bright, clean, colorful daylight civic-mobility UI.
- Page Background Canvas: Soft diagonal daylight wash blending cool sky tint (#F0F9FF) -> crisp white (#FFFFFF) -> soft emerald tint (#ECFDF5).
- Card Surfaces: Frosted translucent white panels (90% white opacity over soft blur), thin cool-slate borders (#E2E8F0 at 80% opacity), generous rounded corners (14-20 px), and soft diffused elevation shadows.
- Primary Ink: Deep Slate (#0F172A) for headings and primary values; Muted Slate (#475569 and #64748B) for secondary labels and metadata.

1.2 Typography
- Display & Section Headings (H1-H4): Plus Jakarta Sans (weights 600-800) with Noto Sans Malayalam fallback.
- Body & Controls: Public Sans (weights 400-600) with Noto Sans Malayalam fallback.
- Technical Identifiers, Scores, PNRs, Fares, Timestamps & JSON: IBM Plex Mono with tabular numerals enabled.

1.3 Semantic Color Tokens
- Critical / Emergency / KSEB / Spam Rejection / Active Hazard:
  Primary Accent: #E11D48 / #EF4444 (Rose / Crimson) | Soft Surface: #FFF1F2
  Usage: Severity 9-10, 112 ERSS alert, KSEB Electrical badge, Spam guardrail banner, Critical corridor hazards.
- High Priority / PWD / Selected 3D Seat / Demo Mode:
  Primary Accent: #F59E0B / #F97316 (Warm Amber / Orange) | Soft Surface: #FFFBEB
  Usage: Severity 7-8, PWD Roads badge, Corroboration boost banner, Selected 3D seat highlight, Rs. 1 Demo Fare toggle.
- Medium Priority / KWA / IRCTC / Dispatched / Focus:
  Primary Accent: #0284C7 / #0EA5E9 (Ocean Sky Blue) | Soft Surface: #F0F9FF
  Usage: Severity 4-6, KWA Water badge, Dispatched status, Officer Dashboard active tab, IRCTC channel.
- Low Priority / Resolved / Sanitation / Available 3D Seat / Origin:
  Primary Accent: #10B981 / #16A34A / #0D9488 (Emerald / Teal) | Soft Surface: #ECFDF5
  Usage: Severity 1-3, Resolved & AI Verified Fix, Waste & Sanitation, Available 3D seats, Origin beacon, Citizen Report active tab.
- Police & Safety / Public Safety Dept / Cyber Crime:
  Primary Accent: #4F46E5 / #1E3A8A (Indigo / Royal Navy) | Soft Surface: #EEF2FF
  Usage: Police & Safety Desk hero & tab, Public Safety & Encroachment, Petition Slip header, Locked House Intimation.
- Booked / Disabled / Invalid / Secondary Chrome:
  Primary Accent: #64748B / #94A3B8 (Slate Gray) | Soft Surface: #F1F5F9
  Usage: Booked 3D seats, Rejected / Invalid status, Secondary actions.

=== SCREEN 1: CITIZEN REPORT (intake) ===
Layout: Full Emergency Helpline Strip across the top, followed by a 2-column split (Left 5/12: Intake Form; Right 7/12: Sticky Triage Result Panel).

Left Column — Citizen Intake Form:
1. Header: Title + concise instruction explaining multimodal photo + English/Malayalam/Manglish triage.
2. 1-Click Test Scenarios Strip (5 quick-fill buttons loading sample photo, location hint, and realistic description):
   - Snapped Power Cable (Manglish — Aluva Ward 14 / KSEB Critical)
   - Main Road Pothole (Malayalam — Kochi Ward 28 / PWD High)
   - Small Curb Puddle (English — Kozhikode Ward 9 / Exaggeration Cross-Check)
   - Overflowing Waste Bin (Manglish — Thrissur Ward 19 / Waste & Sanitation)
   - Indoor Coffee Mug (English — Kottayam Ward 7 / Spam Guardrail Rejection)
3. Photo Upload Zone:
   - Supports drag-and-drop or file picker (JPEG, PNG, WebP, max 8 MB).
   - Once loaded: displays photo preview, filename, file size, and Replace / Remove buttons.
4. Citizen Issue Description:
   - Multi-line text input (up to 2,000 characters) accepting English, Malayalam, or Manglish, paired with Multilingual Voice Control (en-IN / ml-IN).
5. Municipality / Panchayat & Ward (Optional):
   - Single-line text input (up to 200 characters) for local body, ward, or landmark clues.
6. Primary Submit Button ("Run AI Triage"):
   - Disabled until both a photo and non-empty description exist; shows loading state during API call.
   - Calls POST /api/triage with imageBase64, mimeType, description, and locationHint.
   - Post-Triage Behavior:
     * If is_valid_civic_issue === false: saves ticket with workflowStatus = "Rejected", emailAlertStatus = "not_applicable". NEVER sends an officer alert email.
     * If is_valid_civic_issue === true:
       (1) Runs Duplicate Report Clustering (Section 5.1).
       (2) If a matching open ticket in the same department is found (score >= 2): increments corroborationCount (+1), boosts severity_score by +1 (capped at 10), recalculates severity band and SLA, sets wasCorroborationBoosted = true, updates existing ticket, and re-triggers officer EmailJS alert.
       (3) Otherwise: generates ID KSM-YYYYMMDD-XXXX, sets workflowStatus = "Triaged", corroborationCount = 1, saves ticket, and triggers non-blocking officer EmailJS alert (Section 5.4).

Right Column — Triage Result Panel:
- Empty State: 4 numbered triage rule summary cards (Spam Guardrail, Visual Cross-Check, 6-Department Routing, Formal K-SMART Drafting) + clickable list of up to 4 recent triaged tickets.
- Loading State: Animated multimodal analysis skeleton.
- Error State: Clear error alert with Retry button.
- Populated Ticket State:
  * Top toolbar: Segmented toggle ("K-SMART Ticket" vs "Raw JSON"), "Copy JSON" button (with copied confirmation), and "Download" button (exports <ticket-id>.json).
  * Status Banner Row:
    - If invalid: Crimson Spam Guardrail Rejected banner showing rejection_reason.
    - If valid: Live EmailJS status pill ("Sending alert email...", "📧 Alert email flashed to officer", or "⚠️ Email skipped"), alongside workflow status pill (Triaged / Dispatched / Resolved).
    - If boosted by duplicate clustering: Amber-orange banner "Linked to Active Ward Ticket — Priority Boosted!" with "Confirmed by X citizens" badge.
    - If closed via repair verification: Emerald "AI Verified Resolved" badge with audit note.
  * KPI Strip: 10-Segment Visual Severity Meter (color-coded + numeric X/10 + Band), Assigned Department & SLA Card, Detected Language & Location Clues Card.
  * Detail Sections: Visual Severity Reasoning (1 sentence), Multimodal Cross-Check Callout (aligned vs exaggeration warning), Official Third-Person English K-SMART Summary (title + summary), Recommended Field Action, Extracted Landmarks chips.
  * Action Footer Buttons:
    - "Mark Dispatched" / "Mark Resolved" (for valid tickets).
    - Conditional "Escalate to Police Desk" button (shown whenever requires_police_escalation === true, OR department === "Public Safety & Encroachment", OR severity_score >= 8): detects Kerala district from ticket text, pre-populates a draft petition in Police & Safety Desk with ticket ID, summary, landmarks, and photo, and navigates directly to Police & Safety.
    - "View in Ticket Queue" (switches to Officer Dashboard with this ticket selected).


=== SCREEN 2: OFFICER DASHBOARD (queue) ===
Layout: Full-width municipal command view with a 4-card KPI strip on top, a Desk Switcher, filterable data table, and an interactive Inspector panel below.

Top 4-Card Municipal Analytics & KPI Bar (numeric metric, contextual badge, horizontal progress bar, sub-caption):
1. Total Active Hazards: Count of open valid tickets (not Resolved, not Rejected) vs total valid tickets.
2. Critical SLA Alerts: Count of open valid tickets with severity_score >= 7.
3. Resolution Rate %: round(resolvedValidTickets / totalValidTickets * 100)%.
4. Active Police Petitions: Count of open police cases (status !== "Disposed / Closed") + high/critical share indicator.

Desk Switcher Tabs:
- "Municipal LSG Queue" (default)
- "Police Station (SHO) Case Desk" (shows live open count; displays "File New Police Petition" button on the right when active)

View A — Municipal LSG Queue:
- Filter Bar: Search box (matches ID, title, summary, department, category, landmarks, local body, citizen text), Department dropdown (ALL + 6 departments), Workflow Status pills (All, Triaged, Dispatched, Resolved, Rejected).
- Table Columns:
  1. Ticket ID (monospace) + timestamp
  2. Formal Ticket Title + location clue + optional amber "Confirmed by X citizens" badge
  3. Color-coded Department badge
  4. Color-coded Severity badge (X/10 · Band)
  5. Workflow Status pill + emerald "AI Verified Fix" badge when verified
  6. Row Action: "Verify Fix & Resolve" button for open valid tickets (opens Before/After Modal); "Inspect" for resolved/rejected tickets
- Selected Ticket Inspector Panel (below table):
  * Displays original Before Photo, side-by-side After Repair Proof Card (if AI-verified, with timestamp, verification note, and resolution email status), original citizen description, formal K-SMART summary, visual verification note, Raw JSON toggle, Copy JSON.
  * Officer Controls: "Set Triaged", "Mark Dispatched", "Verify Fix & Resolve", and "Delete Ticket".

Modal — Gemini Before/After Repair Verification ("Verify Fix & Resolve"):
- Side-by-side comparison: Left shows original Before (Reported Hazard) photo and ticket summary; Right shows After Repair Photo uploader (JPEG, PNG, WebP, max 7 MB) + 1-click "Load Sample Repaired Photo" button (programmatically generates a clean, resurfaced sunlit asphalt road image).
- Submit ("Run Gemini Repair Audit"): Calls POST /api/verify-repair with after-repair photo and original ticket context.
- If is_resolved === true: displays emerald verification badge + verification_note, marks ticket workflowStatus = "Resolved", saves repairVerification record, and fires non-blocking EmailJS resolution alert ("[RESOLVED • AI VERIFIED]").
- If is_resolved === false: displays crimson rejection notice + verification_note and keeps ticket open for re-upload.

View B — Police Station (SHO) Case Desk:
- Filter Bar: Search box (Case Ref ID, district, station, category, summary) + Status filter buttons (All Cases, Submitted, Assigned to SHO / Beat Officer, Under Inquiry, Disposed / Closed).
- Cases Table: Case Ref ID (KL-XXX-YYYY-XXXX), District & Station, Case Category + [112 EMERGENCY] or [Locked House] tags, Priority badge, Live Status pill, Inspect action.
- SHO Case Inspector Panel:
  * 4 live status selector buttons (Submitted, Assigned to SHO / Beat Officer, Under Inquiry, Disposed / Closed) synchronized live with Police & Safety Desk.
  * Formal Petition Summary, Required Documents Checklist, Actionable Legal Guidance, optional attached evidence preview, and SHO / Beat Officer Official Disposal Remarks textarea + "Save Disposal Remarks" button.
